# 会话-1：NOBEL 首个可玩版本

## 背景与目标

- 用户提供完整国家科技战略模拟需求，要求直接开发可启动、可游玩、可存档的网页版。
- 初始目录无源码、无AGENTS.md、无Git仓库，故在`nobel/`建立独立项目并初始化文档体系。
- 本任务沟通对应会话-1起的连续交付记录；精确代码历史由Sites源仓库的Git提交定位。

## 约束与决策

- React、TypeScript、Vite；模拟引擎不依赖UI与浏览器。
- 所有国家共享模型与规则，差异来自初始数据及参数。
- 金额十亿美元、人口百万人、科研人员千名全时当量；建议首席科学家人数单独计算。
- GDP、人口、研发支出使用2026开局前已公布基线，保留统计年份、估计状态和汇率来源。
- 全国R&D含企业研发，游戏预算属于资源统筹模型，不等同真实财政科技拨款。
- 浏览器localStorage与文件存档替代首版SQLite；便于静态部署和单人运行，尚无云同步。
- 真实机构名称与历史事件有来源；重点科学家虚构，机构运营参数与科技评分明确模拟。

## 主要文件

- `src/types.ts`：领域、国家、项目、人才、机构、事件和存档的统一类型。
- `src/data.ts`：八国历史基线、16名模拟人才、16所真实机构、12种项目、5条历史事件、19条来源。
- `src/engine.ts`：种子随机性、月度科研与AI、季度快照、年度报告、奖项、资源校验及存档。
- `src/App.tsx`：所有游戏操作、管理页面、弹窗与本地存储。
- `src/WorldMap.tsx`、样式文件：真实地理投影、国家节点、协作连线、缩放与响应式指挥中心。
- `tests/engine.test.ts`：11组完整流程与边界回归。
- `AGENTS.md`、`CLAUDE.md`、`.agentdocs/`、`README.md`：长期规范、记录、计划及运行说明。

## 关键实现与风险

- 仅开局或成功读档才开启自动存档；从菜单预览档案不得覆盖已有进度。
- 进度受资金比例、科技依赖、团队能力、机构设备、基础研究和随机性共同影响，不是固定倒计时。
- 年度报告费用、专利和营收按本年实际增量计算。
- 工程化也占用领域预算与科学家；突破后可以更换团队，防止人才外流后无法启动工程化。
- AI使用国家级聚合研发/工程化阶段；与玩家同样受预算、人才及技术前置约束，但管理粒度不同。
- 奖项提升声望和影响力，研究贡献所在地与获奖者现工作地分别描述，不按出生地粗分。
- 地理数据存在无ISO编号的区域，地图key使用名称/序号回退，避免React重复key警告。
- 字体可离线回退；存档仅限当前浏览器/域名，需导出文件迁移。
- 长期数值平衡、所有真实国家、完整奖项归属模型、动态创造未知技术及产业链精细化尚待扩展。

## 验证结果

### TC-001 中美开局及国家限制

- 类型：自动功能测试，优先级高。
- 操作：分别创建CN/US世界，尝试JP玩家开局。
- 预期：不同历史基线、三个有团队的项目；其余国家存在但不可操作。
- 状态：通过。

### TC-002 时间、AI、年度报告与确定性

- 类型：自动功能测试，优先级高。
- 操作：同一种子连续推进365天与分段推进90+275天；推进两年检查各国。
- 预期：世界完全一致、不修改原状态，季度快照与年度报告正确，AI有科研和产业结果。
- 状态：通过。

### TC-003 资源、团队与科研产业化

- 类型：自动功能测试，优先级高。
- 操作：超额预算、重复科学家、跨国配置、停项、扩建、突破后工程化并继续推进。
- 预期：非法资源操作被拒绝；成果与生产分离，投资扣储备，投产后形成收入。
- 状态：通过。

### TC-004 存档与人才恢复

- 类型：自动回归测试，优先级高。
- 操作：序列化/恢复并推进；输入损坏日期、年度报告、国家元数据；更换外流团队。
- 预期：合法存档可重放；损坏数据被拒绝或固定资料恢复；工程化不会永久锁死。
- 状态：通过；共11组测试全部通过。

### TC-005 浏览器完整流程

- 类型：人工浏览器验证，优先级高。
- 操作：菜单→中国开局→新增芯粒封装项目→配置专业人才→模拟一年→4项科研突破→数字孪生工程化→推进14个30天→投产。
- 预期：项目真实演进，产业有收入，全球排名发生变化；保存后刷新可继续。
- 状态：通过；验证时2028-02-25已投产1项，累计产业收入约3.4十亿美元。此为该测试种子的模拟结果，不是固定剧情。

### TC-006 界面、类型与构建

- 类型：工程与视觉验证，优先级高。
- 操作：`npm run build`、`npm test`；检查桌面与390×844手机视口；修复地图key后新页面复查控制台。
- 预期：类型与构建成功，手机无横向溢出，控制台无应用错误，半导体分类榜正确重排。
- 状态：通过；移动端内容宽度386px与可用宽度386px一致；最终页面控制台警告/错误列表为空。
