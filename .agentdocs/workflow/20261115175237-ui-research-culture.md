# 会话-11：无地图策略UI与科研制度

## 背景与目标

- 用户要求移除地图，提升到高质量现代策略游戏UI。
- 中国初始情景需要体现短期执行、工程攻坚优先与对原创探索的较弱支持。
- 在原`main`分支继续开发，起始提交`f606986`，未发现与前次任务的分支差异或用户未提交修改。

## 决策与约束

- 地理地图从主菜单、概览和依赖中完整移除；使用科研态势板、五领域雷达及研究阶段表达科技竞争。
- 创新潜力保存在科学家身上；制度影响其实际发挥，避免国籍直接决定个人天赋。
- 初始制度属于用户要求的可改革情景参数，不能作为实证统计宣传。
- 所有国家适用同一制度公式，玩家与AI均实际受影响。
- 保留旧v1存档的日期、科学家、项目、成果、预算与原基础研究比例。

## 关键实现

制度三轴范围0–100：研究自主性、长期评价权重、工程组织执行。

- 中国新局：32/28/88；美国新局：78/76/72。
- 创新发挥倍率：0.5 + 自主性×0.003 + 长期评价×0.0025。
- 前沿探索倍率：0.58 + 自主性×0.0032 + 长期评价×0.0028。
- 成熟研发倍率：0.82 + 工程执行×0.0025。
- 工程化倍率：0.75 + 工程执行×0.004。
- 单轴改革成本：0.1 + 调整幅度×0.08，单位十亿美元；原值不收费，来回切换不退款。
- 多轴改革先在纯函数状态中完整预演，任一轴失败则不提交中间世界，防止部分扣款。
- 中国当前创新倍率0.666，会令创新潜力92的模拟科学家发挥约61.3；工程化倍率1.102。
- 新局基础研究比例由长期评价权重派生：中国15%、美国30%；旧档保留既有比例。
- 不修改科学家原始创新潜力，改革影响后续发挥和模拟结果。
