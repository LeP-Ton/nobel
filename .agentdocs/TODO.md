# NOBEL 开发计划

## 本次首个可玩版本

- [x] 带历史来源的八国统一模型与五领域依赖
- [x] 财政与领域预算约束，三类科研项目及人才分配
- [x] 随机科研突破、瓶颈与失败，主动工程化与产业收益
- [x] AI自主发展、动态事件、年度报告与综合排名
- [x] 主菜单、国家选择、八个管理界面、时间控制
- [x] 自动存档、手动存档、导入导出及存档校验
- [x] 类型检查、构建、引擎测试、浏览器交互验证
- [x] 完成Sites静态发布配置与交付准备

## 已知边界与后续扩展

- 历史基线使用2026开局前可获得的最近已发布数据，各指标年份不同，不代表2026实测值。
- 首版八国参与模拟，预留统一数据模型用于更多国家；不是全球全部国家的完整数据库。
- 重点科学家使用明确标识的虚构人物，避免虚构真实科学家经历。
- AI采用国家层级聚合项目组合，尚未逐项模拟所有外国科研项目。
- 奖项为历史精选档案与未来模拟荣誉，后续扩展完整奖项与贡献归属模型。
- 普通机构聚合模拟，后续补充真实机构详细统计、专利许可与跨国联合实验室。
- 科研与产业参数属于可解释模型，需要长期平衡和敏感性分析。
- 首版本地存档，后续考虑SQLite/服务端存储、存档迁移与云同步。
- 预留虚拟世界、更多科技领域、产业链和技术标准系统。

- 待扩展完整七类科学奖项与国籍/出生地/研究贡献结构化归属。
- 未知技术目前为预置候选按能力开放，后续实现动态生成方向。
- 产业端尚未细分专利许可、成本、产线、企业和全球市场份额。
- 未验证文件选择器跨设备导入导出、十年以上平衡与完整无障碍审计。
