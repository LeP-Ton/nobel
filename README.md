# 诺贝尔 NOBEL

国家科技战略模拟游戏 · 科研指挥舱版本 0.3。

从中国或美国开启2026年任期，统筹研发预算，配置重点科学家，推进科研突破和工程化，与其他六个自主发展的AI国家竞争。

## 运行

要求 Node.js 22.18+（建议24）及 npm。

```sh
npm install
npm run dev
```

打开终端打印的本地地址。默认端口5173，已占用时会选择其他端口。

```sh
npm run build
npm test
```

`build`同时执行严格TypeScript检查与生产构建，静态结果在`dist/`。配置加载采用Node原生TypeScript支持，避免Windows受限环境中配置打包扫描父目录失败。

## GitHub 与 Pages

- 代码仓库：https://github.com/LeP-Ton/nobel
- 在线游戏：https://lep-ton.github.io/nobel/

推送到`main`后，`.github/workflows/pages.yml`会安装锁定依赖、运行测试、执行类型检查与生产构建，并部署到GitHub Pages。也可在GitHub Actions中手动运行“部署 GitHub Pages”。Pages发布来源使用GitHub Actions。

工作流按Pages配置设置资源基础路径，不需要修改本地或Sites的根路径构建。手动核对项目子路径构建时运行：

```sh
npm run build -- --base=/nobel/
npm run preview -- --base=/nobel/
```

不同域名的浏览器存档不共享；从原站迁移进度时，请先导出JSON，再在新站导入。

## 试玩流程

1. 选择美国或中国；开局继承三项配置了人才的科研项目。
2. 在“国家战略”调整年度预算与五领域分配，合计为100%。
3. “创建科研项目”中选择方向、年度经费和专业匹配的科学家。
4. 使用1×、2×、5×、10×或项目页的“推进一个月”推进时间。
5. 在突破项目详情点击“投资工程化验证”，完成后自动投产并形成实际收益。
6. 点击“年度报告”复盘；第一份报告前可直接模拟推进一年。
7. “存档与读档”支持本机保存、读取、导出和导入JSON文件。

## 默认科研制度情景

中国开局科学家的创新能力直接设为55–64。科研制度初始为研究自主性32、长期考核权重28、工程组织执行88，侧重短期交付和工程攻坚；前沿探索效率约0.76、成熟研发约1.04、工程化约1.10。美国初始三轴为78/76/72，所有国家按相同项目效率公式计算。

这些数值是游戏初始设定。人才界面只显示一个“创新能力”，科研团队直接使用同一数值，不再增加“创新潜力”或“当前创新发挥”。玩家可在“国家战略→国家科研体制”改革项目研究效率，调整会消耗财政。

旧版v1存档会补齐制度，并对仍为旧默认创新值的中国开局科学家进行一次更新；已自定义的能力值保留。原有日期、项目、预算和科技成果保留。默认基础研究比例只影响新游戏：中国15%、美国30%；旧存档保留原有比例。

## 数据与边界

真实国家统计基于开局前已发布数据，各指标年份在国家选择界面列出。全部来源与口径可以在“科技档案→数据来源与模型”查阅。预算代表游戏内全社会研发资源统筹，包含企业研发，不能等同于真实政府拨款。

重点科学家为明确标注的虚构人物。机构名称真实，设备、声望及运营规模为模拟参数。AI采用国家层级项目组合，玩家项目采用单项管理。未知技术当前为预置候选方向，按跨领域能力门槛开放，尚未动态创造新技术模型。完整全球国家/机构数据库、全部七类奖项、专利许可、市场份额和制造成本细分、虚拟世界及云存档见`.agentdocs/TODO.md`。

首版本地存档保存在当前浏览器与站点域名下。部署站点和本地开发地址存档互不共享；迁移时请导出/导入JSON。字体加载失败时自动使用系统字体，核心玩法不依赖第三方字体。

科研装置为原创概念美术，数据、节点、预算、进度和操作仍由代码渲染。背景图片未加载时，所有核心功能仍可使用。“游戏设置→界面动态效果”可关闭轨道、扫描和过渡，动画不推进世界时间。

主菜单与科研中枢中，两侧光束向中央流动，晶格约4秒完成一次青蓝/青绿颜色与明暗呼吸，约26秒缓慢旋转一圈。精细鼠标指针可轻微改变装置视角，移开后平滑回正。小屏幕或图形加速不可用时，使用CSS/SVG兼容动效；关闭动态或系统偏好减少动态时显示静态原图，离屏和后台暂停绘制。
